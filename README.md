# ICE Inventory Offline

Store inventory app for DSD receiving, counts, stock on hand, item maintenance, shelf tags, opening checklist and reports.
Installable on iPad, iPhone and Zebra TC52 (Android). Works with no internet; all data is saved on the device.

Host these files on any HTTPS static host (e.g. Netlify), open the address on the device, and add it to the home screen.
